# Forest-based variable importance measures under correlation and interaction

Analysis code for Conforto F, Generation Scotland, Nicodemus KK, *"Little Red Riding Hood in the Big Forest: Interactions, Correlations and Forest-Based Variable Importances – Which to Choose?"*.

The code computes the random forest (RF) and conditional inference forest (CIF) variable importance measures (VIMs) evaluated in the paper. It runs them on 20 simulated scenarios (500 replicates each) and derives type I error, power and bias/coverage. The paper's applied analysis of Generation Scotland data uses managed-access data and is not part of this repository. VIM labels follow the manuscript and are defined once in [`utils/vim_map.R`](utils/vim_map.R).

> **iBranch.** The interaction Branching VIMs (VIMRF-iBranchT, VIMRF-iBranchB) are included in `src/vim_core.R` (`get_ibranch_tree`, `get_ibranch_branch`) so that this pipeline runs on its own. A stand-alone iBranch implementation is released separately by K. K. Nicodemus: <https://github.com/kristin-nicodemus> *(link to be finalised)*.

## Requirements

- **R ≥ 4.4** with: randomForest, ranger, party, permimp, randomForestSRC, IPMRF, RFSurrogates, treeshap, vip, pdp, h2o, sobolMDA (GitHub), data.table, dplyr, purrr, tidyr, forcats, ggplot2. `utils/install_local.R` installs them into a private library.
- **Python ≥ 3.9** with pandas and numpy, only for `stats/reshape_table.py` (Table S3 layout).
- **A Sun Grid Engine cluster** (`qsub`) for the full runs; the `scripts/submit_*.sh` files target the University of Edinburgh "Eddie" cluster. Every R script can also be run directly with `Rscript` once the environment variables below are set.

## Configuration

```bash
cp config.sh.template config.sh            # simulation study
# edit the paths, then submit every job from the repository root:
qsub scripts/submit_array_light.sh
```

| Variable | Meaning |
|---|---|
| `VIM_ROOT` | Path to this repository |
| `VIM_INPUT_BASE` | Directory with `<scenario>/<scenario>.txt.<i>` |
| `VIM_OUTPUT_DIR` | Where per-dataset `vims_<id>.rds` files are written |
| `VIM_SEED_FILE` | `utils/random_seed`; one seed per replicate |

## Pipeline

### Simulation study

The simulated datasets (500 replicates × 20 scenarios; 2,000 observations and 100 predictors each, generated with `mvtnorm`) are not generated by this repository; the datasets and their generating scripts are available on Zenodo (see the paper's Data Availability statement).

| Step | Command | Output → paper |
|---|---|---|
| Light VIMs (randomForest, ranger, party, IPM, FIRM, TreeSHAP, Sobol-MDA) | `qsub scripts/submit_array_light.sh` → `src/analyse_vims_parallel.R` | `vims_<id>.rds` |
| Heavy VIMs (randomForestSRC, permimp, RFSurrogates, H2O) | `qsub scripts/submit_array_heavy.sh` → `src/analyse_vims_heavy.R` (gap-fill: `submit_array_heavy_strong.sh`) | adds to the same `.rds` |
| Type I error and Wilcoxon tests | `Rscript stats/compute_null_tables.R "$VIM_OUTPUT_DIR"` and `stats/analyse_null_vims.R` | `results/tables/null_tables.csv` → Table 1, Tables S1–S2 |
| Power (1D and 2D) | `Rscript stats/analyse_ha_vims.R "$VIM_OUTPUT_DIR"` | `results/tables/ha_analysis_results.csv` |
| Figures 3–7 | `Rscript stats/generate_visuals.R` | `results/figures/power_and_density/` |
| Density plots (Figure 2) | `qsub scripts/submit_plots.sh` → `stats/plot_densities.R` | `results/figures/density_pdfs/` |
| Bias and coverage of generating model | `Rscript stats/analyse_bias_coverage.R <data_dir> <scenario>` then `python3 stats/reshape_table.py` | `results/tables/bias_coverage/` → Table S3 |
| Run times | `qsub scripts/run_benchmark.sh` → `src/benchmark.R` | `logs/BENCHMARKS.md` → Table 2 |

## Design notes

- **Light/heavy split.** Memory-hungry VIMs (randomForestSRC, permimp, RFSurrogates, H2O) run in a separate array job with larger memory requests. Per-dataset `.rds` files are resumable: a module is skipped if its keys are already present.
- **Smaller forests for costly VIMs.** VIMCIF-Conditional, VIMCIF-FCPI, VIMRF-SMD and VIMRF-MIR use 500 trees; all other VIMs use 1,000 trees and *mtry* = 33.
- **Compact outputs.** TreeSHAP is stored as mean |SHAP| per variable, SMD as the depth vector and H2O as the relative-importance vector, so each `.rds` file is about 250 KB.
- **Seeds.** Each simulated replicate uses `seeds[i]` from `utils/random_seed`.

## Packaging

`scripts/make_tarball.sh` builds `DRS_VIM_code.tar.gz` from the files tracked by git (`git archive`), so drafts, data and local configuration are never included.
